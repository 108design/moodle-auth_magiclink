# Changelog

## 1.0.0 — 4 November 2026

- First stable activation-free release of Magic Link. No 108design account, license key, Plugin Manager or external activation service is required.
- Retains the existing passwordless email sign-in, account-creation controls and optional native Moodle MFA email-factor integration.
- Includes contextual help and the 108design software license with the Moodle Marketplace permission in Section 6a.

Moodle build: `2026110400`. Requires Moodle 4.5 or later.
